# Data folder

**All data in this project is SYNTHETIC unless this file is updated to say otherwise.**
It was generated by `python -m scripts.prepare_data` for development and testing.
It does not describe real incidents, real people or the real safety of any place.

| Folder | Contents |
|---|---|
| `raw/` | Generated data with deliberate defects (missing values, duplicates, bad coordinates) |
| `processed/` | Cleaned data and `data_quality_report.json` (what was fixed or removed) |
| `eda/` | Charts and `eda_summary.md` from `python -m scripts.run_eda` |

Zones are generic "Demo Zone" labels placed around the map centre. They are not real
neighbourhoods. A place with no reports is **unknown**, not safe.
